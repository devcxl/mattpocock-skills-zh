# Triage Labels

技能使用五个规范的 triage 角色。此文件将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | 含义                                       |
| -------------------------- | -------------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue                     |
| `needs-info`               | `needs-info`         | 正等待报告者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，适合交给 AFK agent               |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                               |
| `wontfix`                  | `wontfix`            | 不会采取行动                               |

技能提到某个角色时（例如“应用 AFK-ready triage 标签”），请使用此表中对应的标签字符串。

判断 issue 状态前，请先依据 [`SCOPE.md`](../../SCOPE.md) 评估。拒绝的 issue 以“not planned”原因关闭。
