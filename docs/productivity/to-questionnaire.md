## 它能做什么

`to-questionnaire` 把你无法独自回答的决策转化为一份问卷，交给别人来填写。

## 何时使用

你直接输入 `/to-questionnaire` 来调用它；智能体不会自动触发。

| 你的情况 | 使用 |
| --- | --- |
| 你有一个决策，需要别人的意见 | `to-questionnaire` |
| 你有一个决策，需要多个人的意见 | 同上 |
| 你有一个决策，但你没有足够的信息来独自做出 | 同上 |
| 你有一个决策，但你需要它被记录下来 | 同上——问卷就是记录 |

## 先决条件

- 一个**决策**。`to-questionnaire` 转化的是决策，而不是问题。
- 一个**受众**。`to-questionnaire` 是为别人设计的，而不是为你自己。

## 输出

`to-questionnaire` 把一个 markdown 问卷放在 `.scratch/questionnaire/` 下，以决策名称命名。问卷包含：

- 决策
- 选项
- 每个选项的利弊
- 每个选项的推荐
- 回答问题的地方

## 常见问题

**它生成了一份问卷，然后让我填写。**
这不是 bug——这是设计使然。问卷是给别人填的，不是你。

**它生成了一份问卷，但涵盖了太多内容。**
决策太大了。把它拆分成更小的决策。

**它生成了一份问卷，但内容不够。**
决策太小了。合并它。

**它生成了一份问卷，但问题不对。**
决策不对。重新表述决策。

## 如何判断它是否有效

- 问卷澄清了决策。
- 问卷列出了选项。
- 问卷列出了每个选项的利弊。
- 问卷推荐了一个选项。
- 问卷是可填写的，而不是可读的。

## 它适合在哪里

`to-questionnaire` 是一个**独立技能**，脱离所有流程。它适合在有一个需要别人意见的决策时使用。

- [grill-with-docs](https://aihero.dev/skills-grill-with-docs) 是它用于你可以在对话中做出的决策的对应物。
- [to-spec](https://aihero.dev/skills-to-spec) 是它用于你可以在做出决策后规范化的对应物。

[ask-matt](https://aihero.dev/skills-ask-matt) 在不清楚该用哪个技能时为你路由。
