## 它能做什么

`wait-what` 停止。上一条消息你没理解——重新解释一下。

## 何时使用

你直接输入 `/wait-what` 来调用它；智能体不会自动触发。

| 你的情况 | 使用 |
| --- | --- |
| 智能体失去了你的追踪 | `wait-what` |
| 智能体在误解的基础上构建 | 同上 |
| 智能体使用了你听不懂的术语 | 同上 |
| 对话感觉脱节了 | 同上 |

## 先决条件

- 一个**误解**。`wait-what` 不是用于澄清的——它是用于你感觉智能体已经走偏了的情况。
- 一个**上下文**。`wait-what` 需要知道你已经到达哪里以及需要去哪里。

## 输出

`wait-what` 不会输出任何东西——它重置对话，让智能体重新解释。

## 常见问题

**它没有效果。**
智能体没有遵循指令。输入 `/clear` 并重新开始。

**它让事情变得更糟了。**
智能体过度修正了。输入 `/clear` 并重新开始。

**它一直在触发。**
智能体没有从它的错误中学习。输入 `/clear` 并重新开始。

## 如何判断它是否有效

- 智能体停止了它的轨道。
- 智能体重新解释了。
- 智能体使用了更简单的语言。
- 智能体使用了 `CONTEXT.md` 中的通用语言。
