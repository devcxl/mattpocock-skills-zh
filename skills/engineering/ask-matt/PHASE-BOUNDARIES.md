# 阶段边界

**阶段**是一个会话中的一块工作——盘问、实现、QA。这个定义有意模糊：当一个阶段结束时，你会想"好了，这个搞定了"。

## 选项

当一个阶段结束时，你有一个决策要做出：这个上下文怎么办？选项如下：

| 选项 | 何时使用 |
| --- | --- |
| **继续** | 下一个阶段原样需要这个阶段的内容，或者你还有 smart zone 剩余。这是唯一保持会话作为主要来源的选项，所以先排除它 |
| **`/clear`** | 你身后的一切都是可丢弃的。这是棋盘上最便宜的选项，而且如果你错了，是一去不回的 |
| **handoff** | 有东西需要传递：一个新的 harness、一个新目录、一个同事、一个在阶段中间分叉的侧任务 |
| **Subagent** | 任务范围足够紧凑，可以让你离开键盘运行 |
| **`/compact`** | 以上都不适用。这是默认选项，而且经常落在这里 |

其中两个经常被搞错，所以路由器携带的是顺序而不是列表。`/handoff` 看起来像是窗口之间的通用桥梁，但并非如此：可移植性就是它买到的全部。`/compact` 是树的底部而不是第一个选项，因为它上面的四个问题每个都更便宜或更精确。
