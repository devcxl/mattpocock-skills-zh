name: research
description: 对照高可信度一手来源调查问题，并将发现以 Markdown 文件落库。当用户希望研究某个主题、收集文档或 API 事实、或把阅读跑腿交给后台 agent 时使用。
---

启动一个**后台 agent** 来做研究——这样它阅读时你继续干活。

它的任务：

1. 对照**一手来源**（官方文档、源码、规范、第一方 API）调查问题，而不是它们的二手转述。把每一条声明追溯回拥有它的那份来源。
2. 把发现写入单个 Markdown 文件，每条声明都标注来源。
3. 文件保存到仓库中已有的同类笔记位置——遵循既有约定；若没有，放到一个合理位置并说明在哪里。
